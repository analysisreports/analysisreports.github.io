### 1. FED POLICY STANCE & MARKET PRESSURE GAUGE
- Purpose: Measures the spread between the 1-month Treasury yield and the Federal Funds policy rate / upper limit (DGS1MO - Fed_Policy_Rate) to evaluate market-implied rate cut pressure or funding-driven hawkish stress.
- Data Series Keys:
  - FRED: DGS1MO (Market Yield on U.S. Treasury Securities at 1-Month Constant Maturity)
  - FRED: DFEDTARU (Federal Funds Target Range - Upper Limit) or DFF (Federal Funds Effective Rate)
- Formula:
  Fed_Policy_Spread_bps = (DGS1MO - Fed_Policy_Rate) * 100
- Machine-Executable Logic (Python):
  def fed_policy_spread(dgs1mo, fed_policy_rate):
      if any(v is None or isinstance(v, bool) for v in (dgs1mo, fed_policy_rate)):
          return None
      try:
          if not (math.isfinite(dgs1mo) and math.isfinite(fed_policy_rate)):
              return None
          # Nominal yield and policy target cannot be negative
          if min(dgs1mo, 0) != 0 or min(fed_policy_rate, 0) != 0:
              return None

          raw_spread = (float(dgs1mo) - float(fed_policy_rate)) * 100.0
          if not math.isfinite(raw_spread):
              return None
          spread = round(raw_spread, 2)

          if spread > 4.0:
              status = "HAWKISH_MARKET_PRESSURE"
          elif spread <= -15.0:
              status = "AGGRESSIVE_EASING_PRESSURE"
          elif spread < -4.0:
              status = "MODERATE_EASING_BIAS"
          else:
              status = "BALANCED_POLICY_EQUILIBRIUM"

          return {"spread_bps": spread, "status": status}
      except (TypeError, ValueError):
          return None
- Interpretation:
  - Spread > +4 bps : HAWKISH_MARKET_PRESSURE (Market demands yield above Fed policy ceiling / Acute liquidity tightness / Hawkish stress)
  - Spread <= -15 bps : AGGRESSIVE_EASING_PRESSURE (Market forces aggressive Fed easing / Heavy dovish pressure / Front-running rate cuts)
  - -15 bps < Spread < -4 bps : MODERATE_EASING_BIAS (Moderate dovish tilt / Emerging rate cut expectations)
  - -4 bps to +4 bps : BALANCED_POLICY_EQUILIBRIUM (Fed policy ceiling and market pricing are in full alignment and equilibrium)

### 2. REAL POLICY RATE & RESTRICTIVENESS
- Purpose: Measures the real stance of effective borrowing costs adjusted for headline inflation.
- Data Series Keys:
  - FRED: DFF (Federal Funds Effective Rate)
  - BLS / FRED: CPIAUCSL (Consumer Price Index for All Urban Consumers: All Items - YoY % Change)
- Formula:

- Machine-Executable Logic (Python):
  def real_policy_rate(dff, cpi_yoy):

              return None

          if not math.isfinite(raw_rate):

              status = "ACCOMMODATIVE"

              status = "NEUTRAL"

          return {"real_rate": rate, "status": status}
      except (TypeError, ValueError):

- Interpretation:
  - Real_Rate > 1.5% : RESTRICTIVE (Restrictive stance / Supporting disinflation)
  - 0.0% to 1.5% : NEUTRAL (Neutral monetary policy)
  - Real_Rate < 0.0% : ACCOMMODATIVE (Accommodative policy / Negative real yield)

### 5. NET FED LIQUIDITY INDEX
- Purpose: Calculates free dollar liquidity in the financial system with strict unit standardization by subtracting the Treasury General Account (TGA) and overnight reverse repo (ON RRP) balances from total Federal Reserve assets.
- Scope & Economic Boundary:
  - This index quantifies domestic central bank operational reserve liquidity directly available to money markets and primary dealers.
  - It does NOT encompass broad liquidity measures (e.g., broad money supply M2, commercial bank loan origination, offshore Eurodollar shadow banking liquidity, or collateralized private repo).
- Unit Standard: All three function inputs must be in millions of USD. FRED reports RRPONTSYD in billions of USD; the ingestion code multiplies it by 1,000 exactly once before calling the function. The function does not convert it again. For example, 0.152 billion USD is passed as 152 million USD. Tool callers must likewise convert the raw FRED value before calling.
- Data Series Keys:
  - FRED: WALCL (Federal Reserve Total Assets - Millions USD)
  - FRED: WTREGEN (Treasury General Account / TGA - Millions USD)
  - FRED: RRPONTSYD (Overnight Reverse Repurchase Agreements / ON RRP - Billions USD at source; Millions USD as function input)
- Formula:
  RRP_Millions = RRPONTSYD_Billions * 1,000
  Net_Liquidity_Millions = WALCL - (WTREGEN + RRP_Millions)
  Net_Liquidity_Trillions = Net_Liquidity_Millions / 1,000,000.0
- Machine-Executable Logic (Python):
  def net_fed_liquidity(walcl, wtregen, rrpontsyd, prev_net_liquidity=None):
      if any(v is None or isinstance(v, bool) for v in (walcl, wtregen, rrpontsyd)):
          return None
      try:
          if not (math.isfinite(walcl) and math.isfinite(wtregen) and math.isfinite(rrpontsyd)):
              return None
          # Fed total balance sheet must be strictly positive
          if min(walcl, 0) == walcl:
              return None
          # TGA and ON RRP balance series cannot be negative
          if min(wtregen, 0) != 0 or min(rrpontsyd, 0) != 0:
              return None

          raw_net = float(walcl) - (float(wtregen) + float(rrpontsyd))
          if not math.isfinite(raw_net):
              return None
          net_liq_mil = round(raw_net, 2)
          net_liq_tril = round(raw_net / 1_000_000.0, 3)

          if net_liq_tril >= 6.20:
              status = "EXPANSIVE_LIQUIDITY_SURPLUS"
          elif net_liq_tril <= 5.50:
              status = "RESTRICTIVE_LIQUIDITY_DRAIN"
          else:
              status = "NEUTRAL_LIQUIDITY_EQUILIBRIUM"

          delta = None
          if prev_net_liquidity is not None and not isinstance(prev_net_liquidity, bool):
              if math.isfinite(prev_net_liquidity):
                  delta = round(net_liq_mil - float(prev_net_liquidity), 2)

          return {
              "net_liquidity_mil": net_liq_mil,
              "net_liquidity_tril": net_liq_tril,
              "delta": delta,
              "status": status
          }
      except (TypeError, ValueError):
          return None
- Interpretation:
  - Net_Liquidity >= $6.20T : EXPANSIVE_LIQUIDITY_SURPLUS (Ample central bank reserve liquidity / Risk asset tailwind)
  - $5.50T to $6.20T : NEUTRAL_LIQUIDITY_EQUILIBRIUM (Balanced money market reserves / Baseline funding conditions)
  - Net_Liquidity <= $5.50T : RESTRICTIVE_LIQUIDITY_DRAIN (Contracting reserve liquidity / QT drain / Risk-off headwind)
  - Delta Net_Liquidity > 0 : LIQUIDITY_EXPANSION (Positive week-on-week reserve impulse)
  - Delta Net_Liquidity < 0 : LIQUIDITY_CONTRACTION (Negative reserve impulse)

### 10. TRIFFIN EXTERNAL BALANCE
- Theoretical Foundation: Operationalizes Robert Triffin's (1960) Dilemma ("Gold and the Dollar Crisis"). As the global reserve currency issuer, the United States must supply international liquidity by running structural trade deficits; however, sustained deficits erode systemic confidence while an appreciating dollar strains offshore debtor balance sheets.
- Purpose: Measures the ratio between nominal broad dollar valuation pressure (DTWEXBGS) and monthly US goods/services trade deficit creation (-BOPGSTB/1000 in Billions USD) to quantify offshore dollar shortage and systemic funding friction. Distinguishes structural external deficits (which supply offshore dollar liquidity) from trade surpluses (which drain global dollar liquidity).
- Data Series Keys:
  - FRED: DTWEXBGS (Nominal Broad U.S. Dollar Index)
  - BEA / FRED: BOPGSTB (U.S. Trade Balance: Goods and Services, Balance of Payments - Millions USD)
- Formula:
  If BOPGSTB < 0 (Trade Deficit):
    Trade_Deficit_Bil = -BOPGSTB / 1000.0
    DXY_Deficit_Tension = DTWEXBGS / Trade_Deficit_Bil
  Else If BOPGSTB > 0 (Trade Surplus):
    Trade_Surplus_Bil = BOPGSTB / 1000.0
    Status = "OFFSHORE_DOLLAR_DRAIN_SURPLUS"
- Machine-Executable Logic (Python):
  def triffin_external_balance(dtwexbgs, bopgstb):
      if any(v is None or isinstance(v, bool) for v in (dtwexbgs, bopgstb)):
          return None
      try:
          dxy = float(dtwexbgs)
          trade = float(bopgstb)
          if not (math.isfinite(dxy) and math.isfinite(trade)):
              return None
          if dxy <= 0.0 or trade == 0.0:
              return None

          if trade > 0.0:
              surplus_bil = trade / 1000.0
              tension = round(dxy / surplus_bil, 4)
              return {"tension": tension, "status": "OFFSHORE_DOLLAR_DRAIN_SURPLUS"}

          deficit_bil = -trade / 1000.0
          raw_tension = dxy / deficit_bil
          if not math.isfinite(raw_tension):
              return None
          tension = round(raw_tension, 4)
          status = "RESERVE_CURRENCY_STRAIN" if tension > 1.25 else ("ABUNDANT_OFFSHORE_LIQUIDITY" if tension < 1.00 else "BALANCED_TRIFFIN_EQUILIBRIUM")
          return {"tension": tension, "status": status}
      except (TypeError, ValueError, ZeroDivisionError):
          return None
- Interpretation:
  - Rising Index (> 1.25) : Strong Dollar & External Deficit Fragility (Offshore dollar shortage and funding stress)
  - Falling Index (< 1.00) : Global Financial Conditions Easing
  - Surplus Regime : Global Dollar Drain (US net drain on world dollar liquidity)

### 11. TAYLOR RULE POLICY GAP
- Purpose: Computes the Fed's optimal policy rate and deviation gap based on headline inflation and the output gap.
- Unit Convention & Scaling Standard:
  - All rates and percentage gaps are expressed strictly in **percentage points** (e.g., `2.50` denotes 2.50%, NOT `0.025`).
  - `CPI_YoY` is in percentage points (e.g., `3.2` for 3.2% YoY).
  - `Output_Gap_Pct` is in percentage points (e.g., `-1.2` for a -1.2% output gap relative to potential GDP).
  - Target neutral rate `r*` (`2.0`) and inflation target `pi*` (`2.0`) are in percentage points.
- Data Series Keys:
  - FRED: DFF (Federal Funds Effective Rate - Actual Policy Rate)
  - BLS / FRED: CPIAUCSL (Must be transformed to YoY % Change)
  - BEA / FRED: GDPC1 (Real Gross Domestic Product - Billions USD)
  - CBO / FRED: GDPPOT (Real Potential Gross Domestic Product - Billions USD)
  - Unit requirement: Both series must be labeled "Billions of Chained 2017 Dollars"; unlabeled or different units are rejected rather than implicitly converted.
  - Period requirement: GDPC1 and GDPPOT must refer to the same quarterly observation date (YYYY-MM-DD, first day of the quarter). GDPPOT's latest observation may be a future projection and must not be used for a different GDP quarter.
  - Input guards: GDPPOT must exceed 1.0 (in billions), and the computed output gap must be within +/-50%; invalid or implausible inputs return no model result.
- Baseline Assumptions:
  - Equilibrium Real Neutral Rate (r*): 2.0%
  - Target Inflation (pi*): 2.0%
  - Inflation and output-gap coefficients (alpha and beta): 0.5 each
  - This is a Taylor-style benchmark using headline CPI YoY, not an official Fed policy rate.
- Formula:
  General form: Policy_Rate = r* + inflation + alpha * (inflation - inflation_target) + beta * output_gap_pct
  Output_Gap_Pct = ((GDPC1 - GDPPOT) / GDPPOT) * 100
  Taylor_Optimal_Rate = 2.0 + CPI_YoY + 0.5 * (CPI_YoY - 2.0) + 0.5 * Output_Gap_Pct
  Taylor_Policy_Gap = DFF - Taylor_Optimal_Rate
- Machine-Executable Logic (Python):
  import datetime

  def taylor_policy_gap(dff, cpi_yoy, gdpc1, gdppot, gdpc1_units, gdppot_units, gdpc1_date, gdppot_date):
      if any(v is None or isinstance(v, bool) for v in (dff, cpi_yoy, gdpc1, gdppot)):
          return None
      try:
          if not (math.isfinite(dff) and math.isfinite(cpi_yoy) and math.isfinite(gdpc1) and math.isfinite(gdppot)):
              return None
          # Nominal policy rate cannot be negative (min(v, 0) == 0 check: v >= 0)
          if min(dff, 0) != 0:
              return None
          # GDP inputs use billions of chained 2017 dollars; reject a near-zero denominator.
          if gdpc1 <= 0 or gdppot <= 1.0:
              return None

          expected_units = "billions of chained 2017 dollars"
          normalize_units = lambda value: " ".join(str(value).casefold().split())
          if normalize_units(gdpc1_units) != expected_units or normalize_units(gdppot_units) != expected_units:
              return None

          if not isinstance(gdpc1_date, str) or gdpc1_date != gdppot_date:
              return None
          quarter = datetime.date.fromisoformat(gdpc1_date)
          if quarter.isoformat() != gdpc1_date or quarter.day != 1 or quarter.month not in (1, 4, 7, 10):
              return None

          output_gap_raw = ((gdpc1 / gdppot) - 1.0) * 100.0
          if not math.isfinite(output_gap_raw) or abs(output_gap_raw) > 50.0:
              return None
          output_gap = round(output_gap_raw, 2)
          optimal_rate = round(2.0 + cpi_yoy + 0.5 * (cpi_yoy - 2.0) + 0.5 * output_gap, 2)
          gap = round(dff - optimal_rate, 2)
          if not math.isfinite(gap):
              return None

          if min(gap, -1.00) == gap and gap != -1.00:
              status = "BEHIND_THE_CURVE"
          elif max(gap, 1.00) == gap and gap != 1.00:
              status = "OVER_RESTRICTIVE"
          else:
              status = "OPTIMAL_ALIGNMENT"

          return {
              "policy_gap": gap,
              "optimal_rate": optimal_rate,
              "output_gap": output_gap,
              "status": status
          }
      except (TypeError, ValueError, ZeroDivisionError):
          return None
- Interpretation:
  - Taylor_Policy_Gap < -1.00 : BEHIND_THE_CURVE (Fed behind the curve / Excessively loose)
  - -1.00 to +1.00 : OPTIMAL_ALIGNMENT (Balanced monetary policy stance)
  - Taylor_Policy_Gap > +1.00 : OVER_RESTRICTIVE (Excessively restrictive / Recession risk stance)

### 12. FINANCIAL CONDITIONS TIGHTNESS (CHICAGO FED NFCI)
- Purpose: Monitors whether monetary policy has transmitted to financial markets; tracks composite tightness across debt, equity, and money market risk premiums.
- Data Series Keys:
  - FRED: NFCI (Chicago Fed National Financial Conditions Index)
  - FRED: ANFCI (Adjusted National Financial Conditions Index - Adjusted for Macroeconomic Conditions)
- Formula:
  NFCI_Stress_Level = NFCI
- Machine-Executable Logic (Python):
  def financial_conditions_regime(nfci, anfci):
      if any(v is None or isinstance(v, bool) for v in (nfci, anfci)):
          return None
      try:
          if not (math.isfinite(nfci) and math.isfinite(anfci)):
              return None

          n = round(float(nfci), 3)
          a = round(float(anfci), 3)
          div = round(n - a, 3)
          if not math.isfinite(div):
              return None

          if n > 0.0:
              regime = "TIGHT_FINANCIAL_CONDITIONS"
          elif n == 0.0:
              regime = "BALANCED_FINANCIAL_CONDITIONS"
          else:
              regime = "LOOSE_FINANCIAL_CONDITIONS"

          return {"nfci": n, "anfci": a, "regime": regime, "macro_div": div}
      except (TypeError, ValueError):
          return None
- Interpretation:
  - NFCI > 0.00 : TIGHT_FINANCIAL_CONDITIONS (Tight financial conditions / Tighter than historical average / Financial stress)
  - NFCI == 0.00 : BALANCED_FINANCIAL_CONDITIONS (Historically balanced financial conditions)
  - NFCI < 0.00 : LOOSE_FINANCIAL_CONDITIONS (Loose financial conditions / Abundant liquidity / Risk-on support)

### 13. HIGH YIELD CREDIT SPREAD / OAS
- Purpose: Measures corporate credit default risk and risk appetite contraction in basis points.
- Data Series Keys:
  - ICE BofA / FRED: BAMLH0A0HYM2 (ICE BofA US High Yield Index Option-Adjusted Spread)
  - ICE BofA / FRED: BAMLC0A4CBBB (ICE BofA BBB US Corporate Index Option-Adjusted Spread)
- Formula:
  HY_OAS_Spread_bps = BAMLH0A0HYM2 * 100
- Machine-Executable Logic (Python):
  def high_yield_credit_stress(hy_spread):
      if hy_spread is None or isinstance(hy_spread, bool):
          return None
      try:
          if not math.isfinite(hy_spread):
              return None
          # Credit risk spread must be positive and greater than zero
          if min(hy_spread, 0) == hy_spread:
              return None

          bps = int(round(float(hy_spread) * 100.0))

          if max(bps, 500) == bps:
              status = "CREDIT_CRUNCH_ALARM"
          elif max(bps, 350) == bps:
              status = "ELEVATED_RISK"
          else:
              status = "RISK_APPETITE_HEALTHY"

          return {"spread_bps": bps, "status": status}
      except (TypeError, ValueError):
          return None
- Interpretation:
  - HY_Spread >= 500 bps : CREDIT_CRUNCH_ALARM (Credit crunch alarm / Default surge / Recession signal)
  - 350 bps to 500 bps : ELEVATED_RISK (Softening risk appetite / Caution zone)
  - HY_Spread < 350 bps : RISK_APPETITE_HEALTHY (Low default risk / Healthy corporate funding)

### 14. REAL M2 MONEY MOMENTUM
- Purpose: Detects demand shocks by determining the real rate of expansion or contraction of broad money supply (M2) relative to headline inflation.
- Data Series Keys:
  - FRED: M2SL (M2 Money Supply - Billions of USD, Seasonally Adjusted)
  - BLS / FRED: CPIAUCSL (Consumer Price Index - YoY % Change)
- Formula:
  Real_M2_Growth = M2_YoY_Growth_Pct - CPI_YoY_Pct
- Machine-Executable Logic (Python):
  def real_m2_momentum(m2_yoy, cpi_yoy):
      if any(v is None or isinstance(v, bool) for v in (m2_yoy, cpi_yoy)):
          return None
      try:
          if not (math.isfinite(m2_yoy) and math.isfinite(cpi_yoy)):
              return None

          diff = round(float(m2_yoy) - float(cpi_yoy), 2)
          if not math.isfinite(diff):
              return None

          if diff == 0.0:
              status = "NEUTRAL"
          elif min(diff, 0.0) == diff:
              status = "LIQUIDITY_CONTRACTION"
          else:
              status = "MONETARY_EXPANSION"

          return {"real_m2_growth": diff, "status": status}
      except (TypeError, ValueError):
          return None
- Interpretation:
  - Real_M2_Growth < 0 : LIQUIDITY_CONTRACTION (Real money contraction / Disinflationary demand collapse)
  - Real_M2_Growth == 0 : NEUTRAL (Neutral monetary equilibrium)
  - Real_M2_Growth > 0 : MONETARY_EXPANSION (Real money expansion / Expanding aggregate demand / Inflationary pressure)

### 15. NY FED 10-YEAR TERM PREMIUM (ACM 10-YEAR TERM PREMIUM)
- Purpose: Measures the pure risk premium (fiscal supply pressure and inflation uncertainty) embedded in the 10-year Treasury yield beyond expected short rate paths.
- Data Series Keys:
  - NY Fed / FRED: THREEFYTP10 (Adrian, Crump & Moench 10-Year Treasury Term Premium)
  - FRED: DGS10 (10-Year Treasury Constant Maturity Nominal Yield)
- Formula:
  Expected_Short_Rate_Component = DGS10 - THREEFYTP10
- Machine-Executable Logic (Python):
  def acm_term_premium_breakdown(dgs10, term_premium):
      if any(v is None or isinstance(v, bool) for v in (dgs10, term_premium)):
          return None
      try:
          if not (math.isfinite(dgs10) and math.isfinite(term_premium)):
              return None
          # Nominal 10Y Treasury yield bounds [0.0%, 25.0%]
          if dgs10 < 0.0 or dgs10 > 25.0:
              return None
          # Term premium bounds [-5.0%, +5.0%] to reject basis points vs percent unit errors
          if term_premium < -5.0 or term_premium > 5.0:
              return None

          tp = round(float(term_premium), 2)
          exp_rate = round(float(dgs10) - tp, 2)
          if not math.isfinite(exp_rate):
              return None

          if tp >= 0.50:
              status = "FISCAL_SUPPLY_PRESSURE"
          elif tp <= -0.50:
              status = "FLIGHT_TO_SAFETY"
          else:
              status = "BALANCED_PREMIUM"

          return {
              "term_premium": tp,
              "expected_avg_rate": exp_rate,
              "status": status
          }
      except (TypeError, ValueError):
          return None
- Interpretation:
  - Term_Premium >= 0.50% : FISCAL_SUPPLY_PRESSURE (Duration risk, fiscal supply pressure, or inflation uncertainty)
  - -0.50% to 0.50% : BALANCED_PREMIUM (Balanced risk premium / Normalized Treasury demand)
  - Term_Premium <= -0.50% : FLIGHT_TO_SAFETY (Safe-haven duration demand / Central bank asset purchase scarcity)

### 25.5. REPO LIQUIDITY FRICTION SPREAD ENGINE (SOFR - EFFR SPREAD)
- Purpose: Measures funding market friction and balance sheet constraints by tracking the spread between secured repo financing (SOFR) and unsecured effective Fed funds (EFFR).
- Data Series Keys:
  - FRED: SOFR (Secured Overnight Financing Rate - Percent)
  - FRED: EFFR (Effective Federal Funds Rate - Percent)
- Formula: Repo_Friction_bps = (SOFR - EFFR) * 100
- Machine-Executable Logic (Python):
  def repo_liquidity_friction_spread(sofr_val, effr_val):
      if any(v is None or isinstance(v, bool) for v in (sofr_val, effr_val)):
          return None
      try:
          f_sofr = float(sofr_val)
          f_effr = float(effr_val)
          if not (math.isfinite(f_sofr) and math.isfinite(f_effr)):
              return None
          if f_sofr < 0.0 or f_effr < 0.0:
              return None
          raw_spread = (f_sofr - f_effr) * 100.0
          if not math.isfinite(raw_spread):
              return None
          spread = round(raw_spread, 2)
          if spread > 10.0:
              status = "REPO_MARKET_LIQUIDITY_CRUNCH"
          elif spread >= 5.0:
              status = "SYSTEMIC_CASH_DRAIN_WARNING"
          elif spread < -5.0:
              status = "COLLATERAL_SCARCITY_GLUT"
          else:
              status = "HEALTHY_MONETARY_TRANSMISSION"
          return {"repo_friction_bps": spread, "status": status}
      except (TypeError, ValueError):
          return None
- Interpretation:
  - Repo_Friction_bps > 10.0 bps : REPO_MARKET_LIQUIDITY_CRUNCH (Acute overnight repo funding strain / Cash scarcity / Fed intervention risk)
  - 5.0 bps to 10.0 bps : SYSTEMIC_CASH_DRAIN_WARNING (Systemic cash drain warning / Constrained balance sheet capacity)
  - -5.0 bps to 5.0 bps : HEALTHY_MONETARY_TRANSMISSION (Healthy, balanced monetary transmission mechanism)
  - Repo_Friction_bps < -5.0 bps : COLLATERAL_SCARCITY_GLUT (Excess cash liquidity / Treasury bill scarcity / Collateral squeeze)

### 25.16. YEN CARRY TRADE DISSOLUTION & CROSS-CURRENCY STRESS GAUGE (JPY_CARRY_CRACK)
- Purpose: Evaluates global leveraged Yen Carry Trade unwinding and systemic liquidity shock risks by tracking the narrowing US-Japan interest rate differential against USD/JPY exchange rate velocity.
- Target: economy.json, llms-models.json -> MODEL_25.16_JPY_CARRY_CRACK
- Frequency: Daily (Business Day)
- Canonical Input Series:
  - IND_DFF : Federal Funds Effective Rate (FED)
  - IND_JP_FPOLM_PA : Central Bank Policy Rate for Japan (BoJ / IMF IFS)
  - IND_DEXJPUS : Spot Exchange Rate US Dollars to Japanese Yen
- Mathematical Formulation:
  1. Rate Differential: Spread_Rate = Rate_US - Rate_JP
  2. Currency Momentum: Ret_JPY_30d = ((DEXJPUS_t / DEXJPUS_t_prev) - 1.0) * 100.0  (Negative value indicates JPY appreciation)
  3. Net Carry Return Buffer: Buffer_Carry = Spread_Rate + Ret_JPY_30d
- Machine-Executable Logic (Python):
  def calculate_jpy_carry_crack(rate_us, rate_jp, jpy_fx_mom_pct):
      if any(v is None or isinstance(v, bool) for v in (rate_us, rate_jp, jpy_fx_mom_pct)):
          return None
      try:
          r_us = float(rate_us)
          r_jp = float(rate_jp)
          fx_mom = float(jpy_fx_mom_pct)
          if not (math.isfinite(r_us) and math.isfinite(r_jp) and math.isfinite(fx_mom)):
              return None
          rate_spread = round(r_us - r_jp, 4)
          net_buffer = round(rate_spread + fx_mom, 4)
          if net_buffer <= -1.0 or (fx_mom <= -5.0 and rate_spread <= 3.0):
              status = "UNWIND_LIQUIDATION_CRASH"
          elif net_buffer < 1.5 or fx_mom <= -3.0:
              status = "COMPRESSION_WARNING"
          elif net_buffer >= 3.5 and fx_mom >= -1.0:
              status = "CALM_ACCUMULATION"
          else:
              status = "MANAGED_TIGHTENING"

          return {
              "model_id": "MODEL_25.16_JPY_CARRY_CRACK",
              "rate_spread": rate_spread,
              "fx_momentum_30d_pct": fx_mom,
              "net_carry_buffer": net_buffer,
              "status": status
          }
      except (TypeError, ValueError, OverflowError):
          return None
- Interpretation:
  - status == UNWIND_LIQUIDATION_CRASH : BoJ rate hikes or aggressive Yen appreciation erased carry returns; leveraged funds facing margin calls and forced liquidations; systemic liquidity shock across global equities and crypto.
  - status == COMPRESSION_WARNING : Compressing interest rate differentials or Yen appreciation; carry profit buffer compressed to critical thresholds; early warning alarm.
  - status == MANAGED_TIGHTENING : BoJ normalizes policy in a controlled manner; currency volatility absorbed within manageable bounds.
  - status == CALM_ACCUMULATION : Wide interest rate margin and stable/weak Yen; global carry trade funding flows uninterrupted.

### 26. CENTRAL BANK COMMITTEE DISPERSION & HAWKISHNESS INDEX (COMMITTEE DISPERSION)
- Purpose: Quantifies monetary policy committee (FOMC, ECB, BOE, TCMB) voting distributions across hawkish, dovish, and neutral members to compute directional policy stance (Hawkish/Dovish H-Index) and internal committee fracture (Blau-Simpson Dispersion Index).
- Target: economy.json, llms-models.json -> MODEL_26_COMMITTEE_DISPERSION
- Inputs:
  - n_hawkish : Number of voting members favoring rate hikes or tighter policy stance (non-negative integer)
  - n_dovish  : Number of voting members favoring rate cuts or looser policy stance (non-negative integer)
  - n_neutral : Number of voting members favoring rate pause, hold, or baseline consensus (non-negative integer)
  - n_total   : Total voting member count (optional integer; if provided, must be >= n_hawkish + n_dovish + n_neutral)
- Mathematical Formulation:
  1. Total Committee Votes:
     N_total = n_hawkish + n_dovish + n_neutral (or explicit n_total if verified >= vote sum)
  2. Policy Balance Index (H-Index):
     H_Index = (n_hawkish - n_dovish) / N_total
  3. Voting Member Shares:
     p_hawkish = n_hawkish / N_total
     p_dovish = n_dovish / N_total
     p_neutral = n_neutral / N_total
  4. Internal Committee Diversity / Fracture (Blau-Simpson Dispersion):
     Dispersion = 1.0 - (p_hawkish^2 + p_dovish^2 + p_neutral^2)
- Machine-Executable Logic (Python):
  def committee_dispersion(n_hawkish, n_dovish, n_neutral, n_total=None):
      if any(v is None or isinstance(v, bool) for v in (n_hawkish, n_dovish, n_neutral)):
          return None
      try:
          # Enforce discrete integer counts for voting committee members
          for val in (n_hawkish, n_dovish, n_neutral):
              if isinstance(val, float) and not val.is_integer():
                  return None
              if not isinstance(val, (int, float)):
                  return None
              if not math.isfinite(val) or val < 0:
                  return None

          h = int(n_hawkish)
          d = int(n_dovish)
          neu = int(n_neutral)

          tot = h + d + neu
          if n_total is not None and not isinstance(n_total, bool):
              if isinstance(n_total, float) and not n_total.is_integer():
                  return None
              if not isinstance(n_total, (int, float)) or not math.isfinite(n_total):
                  return None
              f_tot = int(n_total)
              if f_tot >= tot and f_tot > 0:
                  tot = f_tot
              elif f_tot < tot:
                  return None

          if tot <= 0:
              return None

          p_h = h / tot
          p_d = d / tot
          p_neu = neu / tot

          h_index = round((h - d) / tot, 4)
          sum_sq = (p_h ** 2) + (p_d ** 2) + (p_neu ** 2)
          dispersion = round(1.0 - sum_sq, 4)

          # Directional Stance (H-Index Regime)
          if h_index >= 0.50:
              directional_stance = "STRONG_HAWKISH_TILT"
          elif h_index >= 0.15:
              directional_stance = "MODERATE_HAWKISH_BIAS"
          elif h_index <= -0.50:
              directional_stance = "STRONG_DOVISH_TILT"
          elif h_index <= -0.15:
              directional_stance = "MODERATE_DOVISH_BIAS"
          else:
              directional_stance = "BALANCED_NEUTRAL_STANCE"

          # Consensus / Dispersion Regime
          if dispersion <= 0.30:
              consensus_regime = "STRONG_CONSENSUS"
          elif dispersion <= 0.48:
              consensus_regime = "MODERATE_DISSENT"
          else:
              consensus_regime = "HIGH_DISPERSION"

          return {
              "model_id": "MODEL_26_COMMITTEE_DISPERSION",
              "n_total": int(tot),
              "n_hawkish": int(h),
              "n_dovish": int(d),
              "n_neutral": int(neu),
              "share_hawkish_pct": round(p_h * 100.0, 2),
              "share_dovish_pct": round(p_d * 100.0, 2),
              "share_neutral_pct": round(p_neu * 100.0, 2),
              "h_index": h_index,
              "dispersion": dispersion,
              "directional_stance": directional_stance,
              "consensus_regime": consensus_regime
          }
      except (TypeError, ValueError, ZeroDivisionError, OverflowError):
          return None
- Interpretation:
  - Directional Stance (H-Index):
    * H_Index >= 0.50 : STRONG_HAWKISH_TILT (Decisive hawkish bias / Rate hike or aggressive tightening pressure)
    * 0.15 <= H_Index < 0.50 : MODERATE_HAWKISH_BIAS (Moderate tightening tilt)
    * -0.15 < H_Index < 0.15 : BALANCED_NEUTRAL_STANCE (Balanced equilibrium / Neutral policy posture)
    * -0.50 < H_Index <= -0.15 : MODERATE_DOVISH_BIAS (Moderate easing tilt)
    * H_Index <= -0.50 : STRONG_DOVISH_TILT (Decisive dovish bias / Rate cut or aggressive easing pressure)
  - Consensus Regime (Blau-Simpson Dispersion):
    * Dispersion <= 0.30 : STRONG_CONSENSUS (Low dispersion / Robust committee unity and high policy predictability)
    * 0.30 < Dispersion <= 0.48 : MODERATE_DISSENT (Moderate division / Emerging dissent signals)
    * Dispersion > 0.48 : HIGH_DISPERSION (High committee fracture / Deep institutional division and elevated policy uncertainty)
