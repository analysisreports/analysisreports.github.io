## 0. GENERAL METHODOLOGY & EXECUTION RULES (AI DIRECTIVES)

### 0.1. Fundamental Separation of Data Types
AI reasoning agents executing this analytical framework MUST strictly distinguish between the following 4 layers:
1. Empirical Measurements: Observable raw market and institutional data (WALCL, WTREGEN, DFF, Yield Spreads).
2. Calibrated Analytical Indices: Synthetic indicators generated with predefined weights (composite_strategic_score, composite_tension_score).
3. Forecast Probabilities: Event occurrence forecasts over defined horizons (probability_percent).
4. Evidence Confidence: Authority and recency ratings of supporting sources (confidence_score).

### 0.2. Missing Data & Integrity Rule
AI models must never fabricate missing data. When input data is insufficient, values must remain strictly null (None in Python).

#### Rate & Yield Financial Guard:
Interest rates (e.g. FEDFUNDS, DFF, T10Y2Y) and unemployment rates (UNRATE) are already expressed as annualized percentages. Compounding an already annualized percentage metric is a category error that yields deceptive exponential distortions. For all series where units represent percentage rates, compounded annual growth rates (SAAR/CAGR) are strictly suppressed to null (N/A in textual reports).

### 0.6. TIME-SERIES STATISTICAL PROFILER & TREND ENGINE
- Purpose: Computes comprehensive statistical distribution moments, Bessel-corrected volatility, historical anomaly z-scores, moving average trend structures (SMA-6, SMA-12, EMA-6, EMA-12), and linear regression trend slopes for macro time-series observations.
- Formula:
  - Mean: x_bar = (1 / n) * sum(x_i)
  - Median: Middle value of sorted observations (or mean of two middle values)
  - Sample Variance: s^2 = (1 / (n - 1)) * sum((x_i - x_bar)^2)
  - Sample Standard Deviation: s = sqrt(s^2)
  - Z-Score: z = (x_latest - x_bar) / s
  - Simple Moving Average: SMA_k = (1 / k) * sum(x_{n-k+1..n})  (k = 6, 12)
  - Exponential Moving Average: EMA_t = alpha * x_t + (1 - alpha) * EMA_{t-1},  alpha = 2 / (k + 1)
  - Linear Trend Slope: m = (n * sum(t * x_t) - sum(t) * sum(x_t)) / (n * sum(t^2) - (sum(t))^2)
- Machine-Executable Logic (Python):
  def macro_series_profiler(series):
      if not isinstance(series, (list, tuple)) or len(series) < 2:
          return None
      try:
          clean = [float(v) for v in series if _is_num(v) and math.isfinite(float(v))]
          n = len(clean)
          if n < 2:
              return None

          mean_val = sum(clean) / n
          sorted_s = sorted(clean)
          mid = n // 2
          median_val = (sorted_s[mid] if n % 2 != 0 else (sorted_s[mid - 1] + sorted_s[mid]) / 2.0)

          var_val = sum((x - mean_val) ** 2 for x in clean) / (n - 1)
          std_val = math.sqrt(var_val)

          latest = clean[-1]
          z_score = round((latest - mean_val) / std_val, 3) if std_val > 1e-9 else 0.0
          abs_z = abs(z_score)
          if abs_z >= 3.0:
              z_regime = "BLACK_SWAN_OUTLIER"
          elif abs_z >= 2.0:
              z_regime = "ELEVATED_ANOMALY"
          elif abs_z >= 1.0:
              z_regime = "MODERATE_DEVIATION"
          else:
              z_regime = "NORMAL_VARIATION"

          sma_6 = round(sum(clean[-6:]) / 6.0, 4) if n >= 6 else None
          sma_12 = round(sum(clean[-12:]) / 12.0, 4) if n >= 12 else None

          def calc_ema(data, span):
              if len(data) < span:
                  return None
              alpha = 2.0 / (span + 1.0)
              ema = data[0]
              for val in data[1:]:
                  ema = (alpha * val) + ((1.0 - alpha) * ema)
              return round(ema, 4)

          ema_6 = calc_ema(clean, 6)
          ema_12 = calc_ema(clean, 12)

          t_vals = list(range(1, n + 1))
          sum_t = sum(t_vals)
          sum_x = sum(clean)
          sum_tx = sum(t * x for t, x in zip(t_vals, clean))
          sum_t2 = sum(t ** 2 for t in t_vals)
          denom = (n * sum_t2) - (sum_t ** 2)
          slope = round(((n * sum_tx) - (sum_t * sum_x)) / denom, 4) if denom != 0 else 0.0

          if slope > 0.10:
              trend_regime = "STRONG_UPTREND"
          elif slope >= 0.02:
              trend_regime = "MILD_UPTREND"
          elif slope > -0.02:
              trend_regime = "FLAT_SIDEWAYS"
          elif slope >= -0.10:
              trend_regime = "MILD_DOWNTREND"
          else:
              trend_regime = "STRONG_DOWNTREND"

          return {
              "count": n,
              "latest_value": round(latest, 4),
              "mean": round(mean_val, 4),
              "median": round(median_val, 4),
              "std_dev": round(std_val, 4),
              "variance": round(var_val, 4),
              "z_score": z_score,
              "z_score_regime": z_regime,
              "sma_6": sma_6,
              "sma_12": sma_12,
              "ema_6": ema_6,
              "ema_12": ema_12,
              "slope": slope,
              "trend_regime": trend_regime
          }
      except (TypeError, ValueError, ZeroDivisionError):
          return None
- Interpretation:
  - Z-Score Anomaly Regimes:
    - z_score_regime == BLACK_SWAN_OUTLIER : Extreme statistical anomaly beyond historical 3-sigma bands (|z| >= 3.0)
    - z_score_regime == ELEVATED_ANOMALY : Significant regime tension outside 2-sigma historical distribution (2.0 <= |z| < 3.0)
    - z_score_regime == MODERATE_DEVIATION : Moderate historical displacement or nascent trend emergence (1.0 <= |z| < 2.0)
    - z_score_regime == NORMAL_VARIATION : Routine historical market distribution (|z| < 1.0)
  - Trend Direction Regimes:
    - trend_regime == STRONG_UPTREND : Aggressive upward trajectory and accelerating positive momentum (Slope > 0.10)
    - trend_regime == MILD_UPTREND : Moderate positive expansion trend (0.02 <= Slope <= 0.10)
    - trend_regime == FLAT_SIDEWAYS : Range-bound consolidation or structural plateau (-0.02 < Slope < 0.02)
    - trend_regime == MILD_DOWNTREND : Moderate negative contraction trend (-0.10 <= Slope <= -0.02)
    - trend_regime == STRONG_DOWNTREND : Severe downward trajectory and rapid macro deterioration (Slope < -0.10)

### 0.7. LIVE FORECAST BASELINE & SCALE VALIDATION ENGINE
- Purpose: Continuously evaluates live observed market data against historical baseline values established at publication date to track prediction trajectory, delta magnitude, and thesis validity.
- Formula:
  - Delta_Absolute = V_current - V_baseline
  - Delta_Percent = ((V_current - V_baseline) / abs(V_baseline)) * 100.0
- Machine-Executable Logic (Python):
  def forecast_scale_validator(v_baseline, v_current, target_direction, tolerance_pct=2.0):
      if any(v is None or isinstance(v, bool) for v in (v_baseline, v_current)):
          return None
      try:
          v0 = float(v_baseline)
          vt = float(v_current)
          tol = abs(float(tolerance_pct)) if _is_num(tolerance_pct) else 2.0
          if not (math.isfinite(v0) and math.isfinite(vt)) or v0 == 0.0:
              return None

          delta_abs = round(vt - v0, 4)
          delta_pct = round(((vt - v0) / abs(v0)) * 100.0, 2)
          direction = str(target_direction).upper().strip()

          if direction in ("HIGHER", "BULLISH", "HAWKISH", "UP"):
              if delta_pct >= tol:
                  compass = "THESIS_VALIDATED"
              elif delta_pct > -tol:
                  compass = "WITHIN_TOLERANCE_BAND"
              else:
                  compass = "THESIS_INVALIDATED"
          elif direction in ("LOWER", "BEARISH", "DOVISH", "DOWN"):
              if delta_pct <= -tol:
                  compass = "THESIS_VALIDATED"
              elif delta_pct < tol:
                  compass = "WITHIN_TOLERANCE_BAND"
              else:
                  compass = "THESIS_INVALIDATED"
          elif direction in ("RANGE_BOUND", "NEUTRAL", "FLAT"):
              if abs(delta_pct) <= tol:
                  compass = "THESIS_VALIDATED"
              else:
                  compass = "THESIS_INVALIDATED"
          else:
              compass = "UNKNOWN_DIRECTION"

          return {
              "v_baseline": v0,
              "v_current": vt,
              "delta_abs": delta_abs,
              "delta_pct": delta_pct,
              "target_direction": direction,
              "compass_needle": compass
          }
      except (TypeError, ValueError, ZeroDivisionError):
          return None
- Interpretation:
  - compass_needle == THESIS_VALIDATED : Observed market data validates expected direction beyond tolerance band
  - compass_needle == WITHIN_TOLERANCE_BAND : Observed market data remains range-bound within neutral tolerance band
  - compass_needle == THESIS_INVALIDATED : Observed market data contradicts expected directional thesis

## 🏛️ TIER 1: CORE MACROECONOMIC MODELS

### 1. FED POLICY STANCE & MARKET PRESSURE GAUGE
- Purpose: Measures the spread between the 1-month Treasury yield and the Federal Funds target upper limit (DGS1MO - DFEDTARU) to evaluate market-implied rate cut pressure or funding-driven hawkish stress.
- Data Series Keys:
  - FRED: DGS1MO (Market Yield on U.S. Treasury Securities at 1-Month Constant Maturity)
  - FRED: DFEDTARU (Federal Funds Target Range - Upper Limit)
- Formula:
  Fed_Policy_Spread_bps = (DGS1MO - DFEDTARU) * 100
- Machine-Executable Logic (Python):
  def fed_policy_spread(dgs1mo, dfedtaru):
      if any(v is None or isinstance(v, bool) for v in (dgs1mo, dfedtaru)):
          return None
      try:
          if not (math.isfinite(dgs1mo) and math.isfinite(dfedtaru)):
              return None
          # Nominal yield and policy target cannot be negative
          if min(dgs1mo, 0) != 0 or min(dfedtaru, 0) != 0:
              return None

          raw_spread = (float(dgs1mo) - float(dfedtaru)) * 100.0
          if not math.isfinite(raw_spread):
              return None
          spread = round(raw_spread, 2)

          if spread > 4.0:
              status = "HAWKISH_MARKET_PRESSURE"
          elif spread <= -15.0:
              status = "AGGRESSIVE_EASING_PRESSURE"
          elif spread < -4.0:
              status = "MODERATE_EASING_BIAS"
          else:
              status = "BALANCED_POLICY_EQUILIBRIUM"

          return {"spread_bps": spread, "status": status}
      except (TypeError, ValueError):
          return None
- Interpretation:
  - Spread > +4 bps : HAWKISH_MARKET_PRESSURE (Market demands yield above Fed policy ceiling / Acute liquidity tightness / Hawkish stress)
  - Spread <= -15 bps : AGGRESSIVE_EASING_PRESSURE (Market forces aggressive Fed easing / Heavy dovish pressure / Front-running rate cuts)
  - -15 bps < Spread < -4 bps : MODERATE_EASING_BIAS (Moderate dovish tilt / Emerging rate cut expectations)
  - -4 bps to +4 bps : BALANCED_POLICY_EQUILIBRIUM (Fed policy ceiling and market pricing are in full alignment and equilibrium)

### 2. REAL POLICY RATE & RESTRICTIVENESS
- Purpose: Measures the real stance of effective borrowing costs adjusted for headline inflation.
- Data Series Keys:
  - FRED: DFF (Federal Funds Effective Rate)
  - BLS / FRED: CPIAUCSL (Consumer Price Index for All Urban Consumers: All Items - YoY % Change)
- Formula:
  Real_Policy_Rate = DFF - CPI_YoY
- Machine-Executable Logic (Python):
  def real_policy_rate(dff, cpi_yoy):
      if any(v is None or isinstance(v, bool) for v in (dff, cpi_yoy)):
          return None
      try:
          if not (math.isfinite(dff) and math.isfinite(cpi_yoy)):
              return None
          # Nominal policy rate cannot be negative (min(v, 0) == 0 check: v >= 0)
          if min(dff, 0) != 0:
              return None

          raw_rate = float(dff) - float(cpi_yoy)
          if not math.isfinite(raw_rate):
              return None
          rate = round(raw_rate, 2)

  3. Voting Member Shares:
     p_hawkish = n_hawkish / N_total
     p_dovish = n_dovish / N_total
     p_neutral = n_neutral / N_total
  4. Internal Committee Diversity / Fracture (Blau-Simpson Dispersion):
     Dispersion = 1.0 - (p_hawkish^2 + p_dovish^2 + p_neutral^2)
- Machine-Executable Logic (Python):
  def committee_dispersion(n_hawkish, n_dovish, n_neutral=0, n_total=None):
      if any(v is None or isinstance(v, bool) for v in (n_hawkish, n_dovish, n_neutral)):
          return None
      try:
          h = float(n_hawkish)
          d = float(n_dovish)
          neu = float(n_neutral)
          if not (math.isfinite(h) and math.isfinite(d) and math.isfinite(neu)):
              return None
          if h < 0.0 or d < 0.0 or neu < 0.0:
              return None

          tot = h + d + neu
          if n_total is not None and not isinstance(n_total, bool) and math.isfinite(float(n_total)):
              f_tot = float(n_total)
              if f_tot >= tot and f_tot > 0.0:
                  tot = f_tot

          if tot <= 0.0:
              return None

          p_h = h / tot
          p_d = d / tot
          p_neu = neu / tot

          h_index = round((h - d) / tot, 4)
          sum_sq = (p_h ** 2) + (p_d ** 2) + (p_neu ** 2)
          dispersion = round(1.0 - sum_sq, 4)

          # Directional Stance (H-Index Regime)
          if h_index >= 0.50:
              directional_stance = "STRONG_HAWKISH_TILT"
          elif h_index >= 0.15:
              directional_stance = "MODERATE_HAWKISH_BIAS"
          elif h_index <= -0.50:
              directional_stance = "STRONG_DOVISH_TILT"
          elif h_index <= -0.15:
              directional_stance = "MODERATE_DOVISH_BIAS"
          else:
              directional_stance = "BALANCED_NEUTRAL_STANCE"

          # Consensus / Dispersion Regime
          if dispersion <= 0.30:
              consensus_regime = "STRONG_CONSENSUS"
          elif dispersion <= 0.48:
              consensus_regime = "MODERATE_DISSENT"
          else:
              consensus_regime = "HIGH_DISPERSION"

          return {
              "model_id": "MODEL_26_COMMITTEE_DISPERSION",
              "n_total": int(tot),
              "n_hawkish": int(h),
              "n_dovish": int(d),
              "n_neutral": int(neu),
              "share_hawkish_pct": round(p_h * 100.0, 2),
              "share_dovish_pct": round(p_d * 100.0, 2),
              "share_neutral_pct": round(p_neu * 100.0, 2),
              "h_index": h_index,
              "dispersion": dispersion,
              "directional_stance": directional_stance,
              "consensus_regime": consensus_regime
          }
      except (TypeError, ValueError, ZeroDivisionError, OverflowError):
          return None
- Interpretation:
  - Directional Stance (H-Index):
    * H_Index >= 0.50 : STRONG_HAWKISH_TILT (Decisive hawkish bias / Rate hike or aggressive tightening pressure)
    * 0.15 <= H_Index < 0.50 : MODERATE_HAWKISH_BIAS (Moderate tightening tilt)
    * -0.15 < H_Index < 0.15 : BALANCED_NEUTRAL_STANCE (Balanced equilibrium / Neutral policy posture)
    * -0.50 < H_Index <= -0.15 : MODERATE_DOVISH_BIAS (Moderate easing tilt)
    * H_Index <= -0.50 : STRONG_DOVISH_TILT (Decisive dovish bias / Rate cut or aggressive easing pressure)
  - Consensus Regime (Blau-Simpson Dispersion):
    * Dispersion <= 0.30 : STRONG_CONSENSUS (Low dispersion / Robust committee unity and high policy predictability)
    * 0.30 < Dispersion <= 0.48 : MODERATE_DISSENT (Moderate division / Emerging dissent signals)
    * Dispersion > 0.48 : HIGH_DISPERSION (High committee fracture / Deep institutional division and elevated policy uncertainty)

### 30. OFFICIAL MACROECONOMIC RELEASE CALENDARS & COUNTDOWN ENGINE
- Purpose: Deterministically resolves scheduled release dates and computes remaining days for Tier-1 economic releases including CPI, NFP, PPI, PCE Inflation, and GDP.
- Canonical Calendar Sources:
  - BLS Schedule (CPI, NFP, PPI): https://www.bls.gov/schedule/news_release/bls.ics
  - BEA Schedule (PCE, GDP, Trade Balance): https://apps.bea.gov/API/signup/release_dates.json
- Countdown Formula:
  Days_Remaining = (Target_Date - Current_Date).days
  (Both timestamps normalized to midnight 00:00:00 UTC to prevent time-of-day distortion.)
- Status Mapping:
  - Days_Remaining == 0 : "Today"
  - Days_Remaining == 1 : "Tomorrow"
  - Days_Remaining > 1 : str(Days_Remaining) + " days remaining"
  - Days_Remaining < 0 : str(abs(Days_Remaining)) + " days ago"
- Machine-Executable Logic (Python):
  from datetime import datetime

  def macro_release_countdown(target_date_str, current_date_str):
      if not target_date_str or not current_date_str:
          return None
      try:
          t_target = datetime.strptime(str(target_date_str).strip(), '%Y-%m-%d').date()
          t_current = datetime.strptime(str(current_date_str).strip(), '%Y-%m-%d').date()
      except (ValueError, TypeError):
          return None

      delta_days = (t_target - t_current).days

      if delta_days == 0:
          status = "Today"
      elif delta_days == 1:
          status = "Tomorrow"
      elif delta_days > 1:
          status = f"{delta_days} days remaining"
      else:
          status = f"{abs(delta_days)} days ago"

      return {"days_remaining": delta_days, "status": status}
- Execution Directive for AI Agents:
  When querying scheduled release timing for forthcoming macroeconomic data:
  1. Query BLS schedule for CPI, NFP, PPI; query BEA JSON calendar for PCE, GDP.
  2. Identify nearest official scheduled release date (Target_Date).
  3. Execute macro_release_countdown logic to determine exact remaining duration with unambiguous status tags.
