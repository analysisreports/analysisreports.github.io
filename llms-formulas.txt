## 0. GENERAL METHODOLOGY & EXECUTION RULES (AI DIREKTIFLERI)

### 0.1. Fundamental Separation of Data Types (Veri Türlerinin Ayrımı)
AI ajanları bu analitik çerçeveyi uygularken şu 4 katmanı kesin olarak birbirinden ayırmak ZORUNDADIR:
1. Empirical Measurements (Nesnel Ölçümler): Gözlemlenebilir ham piyasa ve kurum verileri (WALCL, WTREGEN, DFF, Faiz Makasları).
2. Calibrated Analytical Indices (Kalibre Edilmiş Endeksler): Tanımlı ağırlıklarla üretilen sentetik göstergeler (composite_strategic_score, composite_tension_score).
3. Forecast Probabilities (Gelecek Senaryo Olasılığı): Tanımlı vadede olayın gerçekleşme tahmini (probability_percent).
4. Evidence Confidence (Kanıt ve Kaynak Güvenilirliği): Veriyi destekleyen kaynakların otorite ve tazelik puanı (confidence_score).

- Reference: Federal Reserve Bank of St. Louis (FRED/ALFRED Methodology)

### Observation Frequencies (n_obs_per_yr):
- Daily (İş Günü) : 260
- Weekly (Haftalık) : 52
- Biweekly (2 Haftalık) : 26
- Monthly (Aylık) : 12
- Quarterly (Çeyreklik) : 4
- Annual (Yıllık) : 1

### Core Transformation Formulas & Python Executables:

import math

def _is_num(val):
    if val is None or isinstance(val, bool) or not isinstance(val, (int, float)):
        return False
    try:
        return math.isfinite(val)
    except (OverflowError, ValueError, TypeError):
        return False

def _is_pos(val):
    if not _is_num(val):
        return False
    return min(val, 0) != val

1. Change (Dönemsel Mutlak Değişim):
   Formula: x(t) - x(t-1)
   Python:
   def fred_change(xt, xt_prev):
       if not (_is_num(xt) and _is_num(xt_prev)):
           return None
       try:
           res = xt - xt_prev
           return round(res, 4) if math.isfinite(res) else None
       except (OverflowError, ValueError):
           return None

2. Change from Year Ago (Yıllık Mutlak Değişim):
   Formula: x(t) - x(t - n_obs_per_yr)
   Python:
   def fred_change_year_ago(xt, xt_year_ago):
       if not (_is_num(xt) and _is_num(xt_year_ago)):
           return None
       try:
           res = xt - xt_year_ago
           return round(res, 4) if math.isfinite(res) else None
       except (OverflowError, ValueError):
           return None

3. Percent Change (Dönemsel Yüzde Değişim - MoM / QoQ):
   Formula: ((x(t) / x(t-1)) - 1) * 100
   Python:
   def fred_percent_change(xt, xt_prev):
       if not (_is_num(xt) and _is_num(xt_prev)) or xt_prev == 0:
           return None
       try:
           res = ((xt / xt_prev) - 1.0) * 100.0
           return round(res, 4) if math.isfinite(res) else None
       except (OverflowError, ValueError, ZeroDivisionError):
           return None

4. Percent Change from Year Ago (Yıllık Yüzde Değişim - YoY):
   Formula: ((x(t) / x(t - n_obs_per_yr)) - 1) * 100
   Python:
   def fred_percent_change_year_ago(xt, xt_year_ago):
       if not (_is_num(xt) and _is_num(xt_year_ago)) or xt_year_ago == 0:
           return None
       try:
           res = ((xt / xt_year_ago) - 1.0) * 100.0
           return round(res, 4) if math.isfinite(res) else None
       except (OverflowError, ValueError, ZeroDivisionError):
           return None

5. Compounded Annual Rate of Change (Bileşik Yıllıklandırılmış Büyüme Hızı - SAAR):
   Formula: (((x(t) / x(t-1)) ** n_obs_per_yr) - 1) * 100
   Python:
   def fred_compounded_annual_rate(xt, xt_prev, n_obs_per_yr):
       if not all(_is_pos(v) for v in (xt, xt_prev, n_obs_per_yr)):
           return None
       try:
           res = (((xt / xt_prev) ** n_obs_per_yr) - 1.0) * 100.0
           return round(res, 4) if math.isfinite(res) else None
       except (OverflowError, ValueError, ZeroDivisionError):
           return None

6. Continuously Compounded Rate of Change (Sürekli Bileşik Değişim Hızı):
   Formula: (ln(x(t)) - ln(x(t-1))) * 100
   Python:
   def fred_continuously_compounded_rate(xt, xt_prev):
       if not all(_is_pos(v) for v in (xt, xt_prev)):
           return None
       try:
           res = (math.log(xt) - math.log(xt_prev)) * 100.0
           return round(res, 4) if math.isfinite(res) else None
       except (OverflowError, ValueError):
           return None

7. Continuously Compounded Annual Rate of Change (Yıllıklandırılmış Sürekli Bileşik Büyüme):
   Formula: ((ln(x(t)) - ln(x(t-1))) * 100) * n_obs_per_yr
   Python:
   def fred_continuously_compounded_annual_rate(xt, xt_prev, n_obs_per_yr):
       if not all(_is_pos(v) for v in (xt, xt_prev, n_obs_per_yr)):
           return None
       try:
           res = ((math.log(xt) - math.log(xt_prev)) * 100.0) * n_obs_per_yr
           return round(res, 4) if math.isfinite(res) else None
       except (OverflowError, ValueError):
           return None

### 1. FED POLITIKA DURUSU (FED POLICY STANCE & EXPECTATION SPREAD)
- Purpose: Piyasanın Fed politika tavanına kıyasla kısa vadeli indirim/artırım beklentisini ölçer.
- Data Series Keys:
  - FRED: DGS1MO (Market Yield on U.S. Treasury Securities at 1-Month Constant Maturity)
  - FRED: DFEDTARU (Federal Funds Target Range - Upper Limit)
- Formula:
  Fed_Policy_Spread_bps = (DGS1MO - DFEDTARU) * 100
- Machine-Executable Logic (Python):
  def fed_policy_spread(dgs1mo, dfedtaru):
      if any(v is None or isinstance(v, bool) for v in (dgs1mo, dfedtaru)):
          return None
      try:
          if not (math.isfinite(dgs1mo) and math.isfinite(dfedtaru)):
              return None
          # Nominal faiz ve politika hedefi negatif olamaz
          if min(dgs1mo, 0) != 0 or min(dfedtaru, 0) != 0:
              return None

          raw_spread = (float(dgs1mo) - float(dfedtaru)) * 100.0
          if not math.isfinite(raw_spread):
              return None
          spread = round(raw_spread, 2)

          if min(spread, -25.0) == spread and spread != -25.0:
              status = "DOVISH_EASING_BIAS"
          elif max(spread, 25.0) == spread and spread != 25.0:
              status = "HAWKISH_TIGHTENING_BIAS"
          else:
              status = "NEUTRAL_PRICING"

          return {"spread_bps": spread, "status": status}
      except (TypeError, ValueError):
          return None
- Interpretation:
  - Spread altı -25 bps : DOVISH_EASING_BIAS (Güçlü Faiz İndirimi Beklentisi)
  - Spread üstü +25 bps : HAWKISH_TIGHTENING_BIAS (Ek Faiz Artırımı Riski)
  - -25 ile +25 arası : NEUTRAL_PRICING (Mevcut Politika ile Piyasa Dengeli)

### 2. REEL POLITIKA FAIZI (REAL POLICY RATE & RESTRICTIVENESS)
- Purpose: Efektif borçlanma maliyetinin resmi manşet enflasyondan arındırılmış reel ağırlığını ölçer.
- Data Series Keys:
  - FRED: DFF (Federal Funds Effective Rate)
  - BLS / FRED: CPIAUCSL (Consumer Price Index for All Urban Consumers: All Items - YoY % Change)
- Formula:
  Real_Policy_Rate = DFF - CPI_YoY
- Machine-Executable Logic (Python):
  def real_policy_rate(dff, cpi_yoy):
      if any(v is None or isinstance(v, bool) for v in (dff, cpi_yoy)):
          return None
      try:
          if not (math.isfinite(dff) and math.isfinite(cpi_yoy)):
              return None
          # Nominal politika faizi negatif olamaz (min(v, 0) == 0 kontrolu: v >= 0)
          if min(dff, 0) != 0:
              return None

          raw_rate = float(dff) - float(cpi_yoy)
          if not math.isfinite(raw_rate):
              return None
          rate = round(raw_rate, 2)

          if max(rate, 1.50) == rate and rate != 1.50:
              status = "RESTRICTIVE"
          elif min(rate, 0.0) == rate and rate != 0.0:
              status = "ACCOMMODATIVE"
          else:
              status = "NEUTRAL"

          return {"real_rate": rate, "status": status}
      except (TypeError, ValueError):
          return None
- Interpretation:
  - Real_Rate üstü 1.5% : RESTRICTIVE (Sıkılaştırıcı / Dezenflasyon Destekleyici)
  - 0.0% ile 1.5% arası : NEUTRAL (Nötr Para Politikası)
  - Real_Rate altı 0.0% : ACCOMMODATIVE (Gevşek Para Politikası / Negatif Reel Getiri)

### 3. SAHM RESESYON KURALI (OFFICIAL SAHM RULE RECESSION INDICATOR)
- Purpose: İşgücü piyasasında 3 aylık hareketli ortalama işsizlik oranının son 12 ayın en düşük 3 aylık ortalamasına göre sıçramasını izleyerek gerçek zamanlı resesyon tespiti yapar.
- Data Series Keys:
  - Official FRED Benchmark: SAHMREALTIME (Real-time Sahm Rule Recession Indicator)
  - Component Series: UNRATE (Civilian Unemployment Rate - Monthly Seasonally Adjusted)
- Formula:
  Sahm_Indicator = Moving_Average_3M(UNRATE) - Min_3M_Average_Prior_12M(UNRATE)
- Machine-Executable Logic (Python):
  def sahm_rule_indicator(unrate_3m_avg, min_prior_3m_avg):
      if any(v is None or isinstance(v, bool) for v in (unrate_3m_avg, min_prior_3m_avg)):
          return None
      try:
          if not (math.isfinite(unrate_3m_avg) and math.isfinite(min_prior_3m_avg)):
              return None
          # Issizlik orani ortalamalari negatif olamaz
          if min(unrate_3m_avg, 0) != 0 or min(min_prior_3m_avg, 0) != 0:
              return None

          raw_diff = float(unrate_3m_avg) - float(min_prior_3m_avg)
          if not math.isfinite(raw_diff):
              return None
          diff = round(raw_diff, 2)

          if max(diff, 0.50) == diff:
              status = "RECESSION_CONFIRMED"
          elif max(diff, 0.30) == diff:
              status = "PRE_RECESSION_WARNING"
          else:
              status = "NORMAL_LABOR_MARKET"

          return {"sahm_value": diff, "status": status}
      except (TypeError, ValueError):
          return None
- Interpretation:
  - Sahm_Indicator 0.50 veya uzeri : RECESSION_CONFIRMED (Tarihsel Resmi Resesyon Sinyali)
  - 0.30 ile 0.50 arası : PRE_RECESSION_WARNING (İşgücü Piyasasında Tehlikeli Soğuma)
  - Sahm_Indicator altı 0.30 : NORMAL_LABOR_MARKET (Sağlıklı İstihdam Patikası)

## 📊 2. KADEME: İLERİ DÜZEY KURUMSAL MAKRO MODELLER

### 5. NET FED LIKIDITESI (NET FED LIQUIDITY INDEX)
- Purpose: Fed bilanço büyüklüğünden Hazine genel hesabı (TGA) ve ters repo (ON RRP) rezervlerini düşerek piyasadaki serbest dolar likiditesini tam birim standardizasyonuyla hesaplar.
- Unit Standard: Girdilerin tamamı Milyon Dolar (Millions of USD) standardında olmalıdır. RRPONTSYD Milyar Dolar çekilirse fonksiyona girmeden önce 1000 ile çarpılarak Milyon Dolar yapılmalıdır.
- Data Series Keys:
  - FRED: WALCL (Federal Reserve Total Assets - Millions USD)
  - FRED: WTREGEN (Treasury General Account / TGA - Millions USD)
  - FRED: RRPONTSYD (Overnight Reverse Repurchase Agreements / ON RRP - Millions USD)
- Formula:
  Net_Liquidity_Millions = WALCL - (WTREGEN + RRPONTSYD)
- Machine-Executable Logic (Python):
  def net_fed_liquidity(walcl, wtregen, rrpontsyd, prev_net_liquidity=None):
      if any(v is None or isinstance(v, bool) for v in (walcl, wtregen, rrpontsyd)):
          return None
      try:
          if not (math.isfinite(walcl) and math.isfinite(wtregen) and math.isfinite(rrpontsyd)):
              return None
          # Fed toplam bilancosu kesinlikle pozitif olmalidir
          if min(walcl, 0) == walcl:
              return None
          # TGA ve ON RRP bakiye serileri negatif olamaz
          if min(wtregen, 0) != 0 or min(rrpontsyd, 0) != 0:
              return None

          raw_net = float(walcl) - (float(wtregen) + float(rrpontsyd))
          if not math.isfinite(raw_net):
              return None
          net_liq = round(raw_net, 2)

          delta = None
          status = None
          if prev_net_liquidity is not None and not isinstance(prev_net_liquidity, bool):
              if math.isfinite(prev_net_liquidity):
                  delta = round(net_liq - float(prev_net_liquidity), 2)
                  if delta == 0.0:
                      status = "NEUTRAL"
                  elif min(delta, 0.0) == delta:
                      status = "LIQUIDITY_CONTRACTION"
                  else:
                      status = "LIQUIDITY_EXPANSION"

          return {
              "net_liquidity_mil": net_liq,
              "delta": delta,
              "status": status
          }
      except (TypeError, ValueError):
          return None
- Interpretation:
  - Delta Net_Liquidity pozitif : LIQUIDITY_EXPANSION (Piyasa Serbest Rezervi Pozitif / Risk-On Destekleyici)
  - Delta Net_Liquidity nötr (0.00) : NEUTRAL (Parasal Denge / Değişmeyen Rezerv)
  - Delta Net_Liquidity negatif : LIQUIDITY_CONTRACTION (Likidite Daralması / Risk-Off / Finansal Sıkılaşma)

  def yield_spread_bps(dgs10, dgs2):

### 7. 10 YILLIK BASABAS ENFLASYON (10-YEAR BREAKEVEN INFLATION RATE)
- Purpose: Tahvil piyasasının önümüzdeki 10 yıl için beklediği yıllık ortalama piyasa enflasyon fiyatlamasını gösterir.
- Data Series Keys:
  - FRED: DGS10 (10-Year Treasury Constant Maturity Nominal Rate)
  - FRED: DFII10 (10-Year Treasury Inflation-Indexed Security / TIPS Yield)
  - FRED Alternative: T10YIE (10-Year Breakeven Inflation Rate)
- Formula:
  Breakeven_Inflation_Rate = DGS10 - DFII10
- Machine-Executable Logic (Python):
  def breakeven_inflation(dgs10, dfii10):
      if any(v is None or isinstance(v, bool) for v in (dgs10, dfii10)):
          return None
      try:
          if not (math.isfinite(dgs10) and math.isfinite(dfii10)):
              return None
          # Nominal faiz negatif olamaz (TIPS reel faizi negatif olabilir)
          if min(dgs10, 0) != 0:
              return None

          rate = round(float(dgs10) - float(dfii10), 2)
          if not math.isfinite(rate):
              return None

          if max(rate, 2.50) == rate and rate != 2.50:
              status = "DE_ANCHORING_RISK"
          elif min(rate, 2.00) == rate and rate != 2.00:
              status = "DEFLATION_RISK"
          else:
              status = "FED_ALIGNED_EQUILIBRIUM"

          return {"breakeven_rate": rate, "status": status}
      except (TypeError, ValueError):
          return None
- Interpretation:
  - Breakeven üstü 2.50% : DE_ANCHORING_RISK (Enflasyon Çıpasında Çözülme Riski)
  - 2.00% ile 2.50% arası : FED_ALIGNED_EQUILIBRIUM (Fed Hedefiyle Uyumlu Dengeli Fiyatlama)
  - Breakeven altı 2.00% : DEFLATION_RISK (Deflasyon / Talep Yetersizliği Fiyatlaması)

### 8. YUMUSAK INIS & BEVERIDGE ORANI (BEVERIDGE CURVE LABOR TIGHTNESS)
- Purpose: İşsizlik artmadan açık iş ilanlarının dengelenip dengelenmediğini ölçer (Açık iş ilanı / İşsiz sayısı oranı).
- Data Series Keys:
  - BLS / FRED: JTSJOL (Job Openings: Total Nonfarm - JOLTS)
  - BLS / FRED: UNEMPLOY (Unemployed Persons - Thousands)
- Formula:
  Beveridge_Ratio = JTSJOL / UNEMPLOY
- Machine-Executable Logic (Python):
  def beveridge_labor_tightness(jtsjol, unemploy):
      if any(v is None or isinstance(v, bool) for v in (jtsjol, unemploy)):
          return None
      try:
          if not (math.isfinite(jtsjol) and math.isfinite(unemploy)):
              return None
          # Kisi ve ilan sayisi negatif olamaz. Issiz sayisi sifir olamaz (zero division).
          if min(jtsjol, 0) != 0 or min(unemploy, 0) != 0 or unemploy == 0:
              return None

          ratio = round(float(jtsjol) / float(unemploy), 2)
          if not math.isfinite(ratio):
              return None

          if max(ratio, 1.50) == ratio and ratio != 1.50:
              status = "OVERHEATED_LABOR"
          elif min(ratio, 1.00) == ratio and ratio != 1.00:
              status = "COOLING_LABOR"
          else:
              status = "SOFT_LANDING_BALANCE"

          return {"beveridge_ratio": ratio, "status": status}
      except (TypeError, ValueError, ZeroDivisionError):
          return None
- Interpretation:
  - Ratio üstü 1.50 : OVERHEATED_LABOR (Aşırı Isınmış İşgücü Piyasası / Ücret Enflasyonu Riski)
  - 1.00 ile 1.50 arası : SOFT_LANDING_BALANCE (Yumuşak İniş Patikası / Dengeli İstihdam)
  - Ratio altı 1.00 : COOLING_LABOR (Zayıflayan İstihdam Talebi / İşsizlik Baskısı Artıyor)

### 9. FINANSAL BASKILANMA & BORC CEVRILEBILIRLIK (FINANCIAL REPRESSION INDEX)
- Purpose: Negatif reel getiri ortamında kamu borcunun reel eritilmesi veya yüksek reel faizle borç krizine girme riskini puanlar.
- Data Series Keys:
  - FRED: DGS10 (10-Year Nominal Treasury Yield)
  - BLS / FRED: CPIAUCSL (CPI YoY % Change)
  - FRED: GFDEGDQ188S (Federal Debt: Total Public Debt as Percent of Gross Domestic Product)
- Formula:

          return None
      try:
          t_target = datetime.strptime(str(target_date_str).strip(), '%Y-%m-%d').date()
          t_current = datetime.strptime(str(current_date_str).strip(), '%Y-%m-%d').date()
      except (ValueError, TypeError):
          return None

      delta_days = (t_target - t_current).days

      if delta_days == 0:
          status = "Bugun"
      elif delta_days == 1:
          status = "Yarin"
      elif max(delta_days, 2) == delta_days:
          status = str(delta_days) + " gun sonra"
      else:
          status = str(abs(delta_days)) + " gun once"

      return {"days_remaining": delta_days, "status": status}
