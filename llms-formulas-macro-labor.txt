### 3. OFFICIAL SAHM RULE RECESSION INDICATOR
- Purpose: Detects real-time recession onset by tracking whether the 3-month moving average of the unemployment rate exceeds its minimum 3-month average from the prior 12 months by 0.50 percentage points or more.
- Data Series Keys:
  - Official FRED Benchmark: SAHMREALTIME (Real-time Sahm Rule Recession Indicator)
  - Component Series: UNRATE (Civilian Unemployment Rate - Monthly Seasonally Adjusted)
- Formula:
  Sahm_Indicator = Moving_Average_3M(UNRATE) - Min_3M_Average_Prior_12M(UNRATE)
- Machine-Executable Logic (Python):
  def sahm_rule_indicator(unrate_3m_avg, min_prior_3m_avg):
      if any(v is None or isinstance(v, bool) for v in (unrate_3m_avg, min_prior_3m_avg)):
          return None
      try:
          if not (math.isfinite(unrate_3m_avg) and math.isfinite(min_prior_3m_avg)):
              return None
          # Unemployment rate averages cannot be negative
          if min(unrate_3m_avg, 0) != 0 or min(min_prior_3m_avg, 0) != 0:
              return None

          raw_diff = float(unrate_3m_avg) - float(min_prior_3m_avg)
          if not math.isfinite(raw_diff):
              return None
          diff = round(raw_diff, 2)

          if max(diff, 0.50) == diff:
              status = "RECESSION_CONFIRMED"
          elif max(diff, 0.30) == diff:
              status = "PRE_RECESSION_WARNING"
          else:
              status = "NORMAL_LABOR_MARKET"

          return {"sahm_value": diff, "status": status}
      except (TypeError, ValueError):
          return None
- Interpretation:
  - Sahm_Indicator >= 0.50 : RECESSION_CONFIRMED (Official historical recession trigger)
  - 0.30 to 0.50 : PRE_RECESSION_WARNING (Dangerous labor market cooling)
  - Sahm_Indicator < 0.30 : NORMAL_LABOR_MARKET (Healthy employment path)

### 8. BEVERIDGE CURVE LABOR TIGHTNESS
- Purpose: Measures whether job openings are normalizing without driving up unemployment (Job Openings to Unemployed ratio).
- Data Series Keys:
  - BLS / FRED: JTSJOL (Job Openings: Total Nonfarm - JOLTS)
  - BLS / FRED: UNEMPLOY (Unemployed Persons - Thousands)
- Formula:
  Beveridge_Ratio = JTSJOL / UNEMPLOY
- Machine-Executable Logic (Python):
  def beveridge_labor_tightness(jtsjol, unemploy):
      if any(v is None or isinstance(v, bool) for v in (jtsjol, unemploy)):
          return None
      try:
          if not (math.isfinite(jtsjol) and math.isfinite(unemploy)):
              return None
          # Counts cannot be negative. Unemployed count cannot be zero (zero division guard).
          if min(jtsjol, 0) != 0 or min(unemploy, 0) != 0 or unemploy == 0:
              return None

          ratio = round(float(jtsjol) / float(unemploy), 2)
          if not math.isfinite(ratio):
              return None

          if max(ratio, 1.50) == ratio and ratio != 1.50:
              status = "OVERHEATED_LABOR"
          elif min(ratio, 1.00) == ratio and ratio != 1.00:
              status = "COOLING_LABOR"
          else:
              status = "BALANCED_LABOR_TIGHTNESS"

          return {"beveridge_ratio": ratio, "status": status}
      except (TypeError, ValueError, ZeroDivisionError):
          return None
- Interpretation:
  - Ratio > 1.50 : OVERHEATED_LABOR (Overheated labor market / Wage inflation risk)
  - 1.00 to 1.50 : BALANCED_LABOR_TIGHTNESS (Soft landing trajectory / Balanced employment)
  - Ratio < 1.00 : COOLING_LABOR (Weakening labor demand / Rising unemployment pressure)

- Data Series Keys:
  - Multpl / FRED Proxy: SP500_EARNINGS_YIELD (S&P 500 Trailing/Forward Earnings Yield / 1/PE * 100)

- Formula:
  Equity_Risk_Premium_Pct = Earnings_Yield - DGS10
- Machine-Executable Logic (Python):

          return None
      try:
          if not (math.isfinite(earnings_yield) and math.isfinite(dgs10)):
              return None
          # Nominal 10Y Treasury yield cannot be negative (min(v, 0) == 0 check: v >= 0)

- Interpretation:

  - 0.50% to 2.50% : FAIR_VALUE (Macro balanced equity valuation zone)
  - ERP > 2.50% : ATTRACTIVE_STOCKS (Equities undervalued / Attractive risk premium / Supportive for equity allocations)

  - BEA / FRED: GDP (Gross Domestic Product - Nominal Billions of USD)
- Formula:
  Buffett_Ratio_Pct = (Total_Equities_Market_Value_mil / (GDP_bil * 1000.0)) * 100

  def buffett_indicator(market_val, gdp_val):

              return None

          if min(market_val, 0) == market_val or min(gdp_val, 0) == gdp_val:

          raw_ratio = (market_val / gdp_mil) * 100.0

          return None
- Interpretation:

  - 140.0% to 180.0% : OVERVALUED (Market decoupled from real economy / Stretched valuation)
  - 100.0% to 140.0% : FAIR_VALUED (Balanced market valuation)
  - Ratio < 100.0% : UNDERVALUED (Equity market undervalued / Attractive entry territory)

### 23. OKUN GAP (GROWTH-EMPLOYMENT DIVERGENCE)
- Purpose: Tests historical elasticity between real GDP growth and changes in unemployment to detect 'jobless growth' or latent labor market deterioration.
- Data Series Keys:
  - BEA / FRED: GDPC1 (Real GDP - YoY % Change)
  - BLS / FRED: UNRATE (Civilian Unemployment Rate - YoY Change in Percentage Points)
- Baseline Assumptions:
  - Potential Real GDP Growth: 2.0%
  - Okun Beta Coefficient: -0.5
- Formula:
  Expected_Unemployment_Delta = -0.5 * (Real_GDP_YoY - 2.0)
  Okun_Gap = Actual_Unemployment_Delta - Expected_Unemployment_Delta
- Machine-Executable Logic (Python):
  def okun_labor_gap(actual_unrate_delta, real_gdp_yoy):
      if any(v is None or isinstance(v, bool) for v in (actual_unrate_delta, real_gdp_yoy)):
          return None
      try:
          if not (math.isfinite(actual_unrate_delta) and math.isfinite(real_gdp_yoy)):
              return None
          expected_delta = -0.5 * (real_gdp_yoy - 2.0)
          gap = round(actual_unrate_delta - expected_delta, 2)

          if max(gap, 0.50) == gap:
              status = "JOBLESS_GROWTH_WARNING"
          elif min(gap, -0.50) == gap:
              status = "LABOR_HOARDING"
          else:
              status = "BALANCED_OKUN_EQUILIBRIUM"

          return {"okun_gap": gap, "status": status}
      except (TypeError, ValueError):
          return None
- Interpretation:
  - Okun_Gap > +0.50 : JOBLESS_GROWTH_WARNING (Unemployment rising despite growth / Productivity or structural disruption)
  - -0.50 to +0.50 : BALANCED_OKUN_EQUILIBRIUM (Growth and employment in historical balance)
  - Okun_Gap < -0.50 : LABOR_HOARDING (Firms retaining employees despite sluggish growth / Resilient employment)

  - Breakeven Growth Band: 100k - 150k

  def labor_dual_track_matrix(payems_mom, unrate_delta, civpart_delta):

      except (TypeError, ValueError):
          return None
- Interpretation:

### 23.2. TOTAL FUNDS FLOW AND VELOCITY MOMENTUM (TOTAL FUNDS FLOW)
- Purpose: Models real and financial transaction liquidity volume, effective monetary flow, and asset inflation pressure by multiplying broad money supply (M2) by the velocity of money (M2V). (Note: As M2V is quarterly, M2SL observations must be aligned to quarterly frequency).

  - FRED: M2SL (M2 Money Supply - Billions of USD, Seasonally Adjusted)
  - FRED: M2V (Velocity of M2 Money Stock - Quarterly)
- Formula:
  Total_Funds_Flow = M2SL * M2V
- Machine-Executable Logic (Python):
  def total_funds_flow_model(m2_level, m2_velocity, prev_tff=None):

      try:
          if not (math.isfinite(m2_level) and math.isfinite(m2_velocity)):
              return None
          if min(m2_level, 0) == m2_level or min(m2_velocity, 0) == m2_velocity:
              return None

          raw_tff = float(m2_level) * float(m2_velocity)
          if not math.isfinite(raw_tff):
              return None
          tff_val = round(raw_tff, 2)

          mom_change = None
          status = "BALANCED_LIQUIDITY_FLOW"
          if prev_tff is not None and not isinstance(prev_tff, bool) and math.isfinite(prev_tff) and prev_tff > 0:
              mom_change = round(((tff_val / float(prev_tff)) - 1.0) * 100.0, 2)
              if max(mom_change, 2.0) == mom_change and mom_change != 2.0:
                  status = "EXCESS_VELOCITY_INFLATION"
              elif min(mom_change, 0.0) == mom_change and mom_change != 0.0:
                  status = "LIQUIDITY_STAGNATION"

              "total_funds_flow": tff_val,

          }
      except (TypeError, ValueError, ZeroDivisionError):
          return None
- Interpretation:
  - status == EXCESS_VELOCITY_INFLATION : Excessive Liquidity Acceleration & Asset Bubble Inflation Risk (TFF QoQ > 2.0%)
  - status == BALANCED_LIQUIDITY_FLOW : Balanced Liquidity Flow (0.0% <= TFF QoQ <= 2.0%)
  - status == LIQUIDITY_STAGNATION : Velocity Collapse, Liquidity Freeze & Deflationary Contraction Risk (TFF QoQ < 0.0%)

          return None
      try:
          if not (math.isfinite(icsa_yoy) and math.isfinite(unrate_delta)):
              return None

          claims_yoy = float(icsa_yoy)
          u_delta = float(unrate_delta)

          # Prevent drops in unemployment rate from generating false stress signals
          effective_u_delta = max(0.0, u_delta)
          raw_index = claims_yoy - (effective_u_delta * 10.0)
          if not math.isfinite(raw_index):
              return None
          index = round(raw_index, 2)

          if max(claims_yoy, 15.0) == claims_yoy and max(index, 15.0) == index and index != 15.0:
              status = "HIDDEN_CRISIS_UNFOLDING"
          elif max(claims_yoy, 8.0) == claims_yoy and max(index, 5.0) == index and index != 5.0:
              status = "EARLY_WARNING_CRACK"
          else:
              status = "LABOR_MARKET_ALIGNED"

          return {"crack_index": index, "claims_yoy": claims_yoy, "status": status}
      except (TypeError, ValueError):
          return None
- Interpretation:
  - status == HIDDEN_CRISIS_UNFOLDING : Weekly claims surging rapidly while official unemployment has not reacted (Latent recession onset / Claims growth > 15%)
  - status == EARLY_WARNING_CRACK : Initial cracks emerging in the labor market (Leading crack signal / Claims growth > 8%)
  - status == LABOR_MARKET_ALIGNED : Data balanced or official unemployment moving in lockstep with claims (Healthy employment path)

### 25. TERMS OF TRADE (TOT)
- Purpose: Measures sovereign purchasing power, terms-of-trade welfare transfers, and current account fragility by evaluating the ratio of export prices to import prices.
- Data Series Keys:
  - BLS / FRED (Export Price Index): IQ (U.S. Export Price Index - All Commodities)
  - BLS / FRED (Import Price Index): IR (U.S. Import Price Index - All Commodities)
- Formula:
  Terms_Of_Trade = (Export_Price_Index / Import_Price_Index) * 100
- Machine-Executable Logic (Python):
  def terms_of_trade_index(export_idx, import_idx):
      if any(v is None or isinstance(v, bool) for v in (export_idx, import_idx)): return None
      try:
          if min(export_idx, 0) == export_idx or min(import_idx, 0) == import_idx:
              return None
          res = (export_idx / import_idx) * 100.0
          return round(res, 2) if math.isfinite(res) else None
      except (TypeError, ValueError, ZeroDivisionError):
          return None
- Interpretation:
  - TOT > 100.0 : FAVORABLE_TRADE (Export revenue purchasing power expanding / Positive terms of trade)
  - TOT == 100.0 : BASELINE_EQUILIBRIUM (Historical baseline equilibrium)
  - TOT < 100.0 : DETERIORATING_TERMS (Imported goods relatively more expensive / Real income loss & current account pressure)

### 25.2. STICKY VS. FLEXIBLE CPI SPREAD
- Purpose: Evaluates structural core inflation persistence versus commodity-driven transient price shocks by measuring the spread between sticky CPI (services, shelter) and flexible CPI (fuel, food).
- Data Series Keys:
  - FRED: STICKYCPIM157SFRBATL (Sticky Consumer Price Index less Food and Energy - YoY % Change)
  - FRED: FLEXCPIM157SFRBATL (Flexible Consumer Price Index less Food and Energy - YoY % Change)
- Formula: Sticky_Impulse = Sticky_CPI_YoY - Flexible_CPI_YoY
- Machine-Executable Logic (Python):
  def sticky_flexible_cpi_spread(sticky_cpi_yoy, flex_cpi_yoy):
      if any(v is None or isinstance(v, bool) for v in (sticky_cpi_yoy, flex_cpi_yoy)):
          return None
      try:
          f_sticky = float(sticky_cpi_yoy)
          f_flex = float(flex_cpi_yoy)
          if not (math.isfinite(f_sticky) and math.isfinite(f_flex)):
              return None
          raw_impulse = f_sticky - f_flex
          if not math.isfinite(raw_impulse):
              return None
          impulse = round(raw_impulse, 2)
          if impulse > 2.0:
              status = "STRUCTURAL_INFLATION_TRAP"
          elif impulse < -2.0:
              status = "TRANSITORY_INFLATION_SURGE"
          else:
              status = "BALANCED_DISINFLATION_PATH"
          return {"sticky_impulse": impulse, "status": status}
      except (TypeError, ValueError):
          return None
- Interpretation:
  - Sticky_Impulse > 2.0% : STRUCTURAL_INFLATION_TRAP (Sticky inflation pressure / Shelter & services rigidity / Core inflation trap)
  - Sticky_Impulse < -2.0% : TRANSITORY_INFLATION_SURGE (Transient commodity/energy price surge / Flexible price spike)
  - -2.0% to 2.0% : BALANCED_DISINFLATION_PATH (Coherent and balanced disinflation trajectory)

### 25.11. FULL-TIME VS. INVOLUNTARY PART-TIME CRACK GAUGE
- Purpose: Detects hidden labor market fragility by comparing the annual surge in involuntary part-time workers against changes in full-time employment, exposing structural deterioration obscured by headline NFP figures.
- Data Series Keys:
  - FRED: LNS12500000 (Employed, Usually Work Full Time - Monthly Level, in Thousands)
  - FRED: LNS12032194 (Employed, Part-Time for Economic Reasons - Monthly Level, in Thousands)
- Formula: 
  Part_Time_Econ_YoY_Pct = ((LNS12032194(t) / LNS12032194(t-12)) - 1) * 100
  Full_Time_YoY_Pct = ((LNS12500000(t) / LNS12500000(t-12)) - 1) * 100
  Crack_Spread = Part_Time_Econ_YoY_Pct - Full_Time_YoY_Pct
- Machine-Executable Logic (Python):
  def hidden_employment_crack_gauge(part_time_econ_level_current, part_time_econ_level_yr_ago, full_time_level_current, full_time_level_yr_ago):
      if any(v is None or isinstance(v, bool) for v in (part_time_econ_level_current, part_time_econ_level_yr_ago, full_time_level_current, full_time_level_yr_ago)):
          return None
      try:
          pt_curr = float(part_time_econ_level_current)
          pt_yr = float(part_time_econ_level_yr_ago)
          ft_curr = float(full_time_level_current)
          ft_yr = float(full_time_level_yr_ago)
          
          if not all(math.isfinite(x) for x in (pt_curr, pt_yr, ft_curr, ft_yr)):
              return None
          if pt_yr <= 0 or ft_yr <= 0 or pt_curr < 0 or ft_curr < 0:
              return None
              
          pt_yoy = ((pt_curr / pt_yr) - 1.0) * 100.0
          ft_yoy = ((ft_curr / ft_yr) - 1.0) * 100.0
          raw_spread = pt_yoy - ft_yoy
          
          if not math.isfinite(raw_spread):
              return None
              
          spread = round(raw_spread, 2)
          pt_yoy_rounded = round(pt_yoy, 2)
          
          if spread > 30.0 and pt_yoy_rounded > 15.0:
              status = "ACUTE_LABOR_MARKET_FRACTURE_RECESSION"
          elif spread > 18.0:
              status = "STRUCTURAL_EMPLOYMENT_WEAKENING_SIGNAL"
          elif spread < -10.0:
              status = "ROBUST_FULL_TIME_EXPANSION"
          else:
              status = "STABLE_EMPLOYMENT_COMPOSITION"
              
          return {"crack_spread_pct": spread, "part_time_yoy_pct": pt_yoy_rounded, "status": status}
      except (TypeError, ValueError):
          return None
- Interpretation:
  - Crack_Spread > 30.0% and Part_Time_YoY > 15.0% : ACUTE_LABOR_MARKET_FRACTURE_RECESSION (Acute labor market fracture / Companies replacing full-time with part-time staff / High-conviction recession signal)
  - Crack_Spread > 18.0% : STRUCTURAL_EMPLOYMENT_WEAKENING_SIGNAL (Structural labor softening / Emerging cracks obscured by headline data)
  - -10.0% to 18.0% : STABLE_EMPLOYMENT_COMPOSITION (Stable employment composition / No unusual labor market distortion)
  - Crack_Spread < -10.0% : ROBUST_FULL_TIME_EXPANSION (Robust full-time job creation / Resilient labor market)

### 25.13. LABOR MARKET MOMENTUM INDEX (LMMI / EMME)
- Purpose: Couples the annual percentage growth of Nonfarm Payrolls (PAYEMS) with the annual percentage point change in the Civilian Unemployment Rate (UNRATE) to measure net momentum, structural deceleration, and employment slack pressure on the Federal Reserve monetary policy reaction function.
- Data Series Keys:
  - BLS / FRED: PAYEMS (All Employees, Total Nonfarm - Monthly Level, in Thousands)
  - BLS / FRED: UNRATE (Civilian Unemployment Rate - Monthly Percent, %)
- Formula:
  PAYEMS_YoY_Pct = ((PAYEMS(t) / PAYEMS(t-12)) - 1.0) * 100.0
  UNRATE_YoY_Diff = UNRATE(t) - UNRATE(t-12)
  LMMI = PAYEMS_YoY_Pct - UNRATE_YoY_Diff
  Employment_Strength_Ratio = PAYEMS_YoY_Pct * (1.0 / UNRATE(t))
- Machine-Executable Logic (Python):
  def labor_market_momentum_index(payems_current, payems_yr_ago, unrate_current, unrate_yr_ago, prev_lmmi=None):
      if any(v is None or isinstance(v, bool) for v in (payems_current, payems_yr_ago, unrate_current, unrate_yr_ago)):
          return None
      try:
          p_curr = float(payems_current)
          p_yr = float(payems_yr_ago)
          u_curr = float(unrate_current)
          u_yr = float(unrate_yr_ago)

          if not all(math.isfinite(x) for x in (p_curr, p_yr, u_curr, u_yr)):
              return None
          if p_curr <= 0.0 or p_yr <= 0.0 or u_curr <= 0.0 or u_yr < 0.0:
              return None

          p_growth = ((p_curr / p_yr) - 1.0) * 100.0
          u_diff = u_curr - u_yr
          raw_lmmi = p_growth - u_diff

          if not math.isfinite(raw_lmmi):
              return None

          lmmi = round(raw_lmmi, 2)
          p_growth_r = round(p_growth, 2)
          u_diff_r = round(u_diff, 2)
          strength_ratio = round(p_growth * (1.0 / u_curr), 2) if u_curr > 0 else None

          # Dynamic momentum direction check if historical LMMI benchmark is provided
          if prev_lmmi is not None and not isinstance(prev_lmmi, bool):
              p_lmmi = float(prev_lmmi)
              if math.isfinite(p_lmmi):
                  if lmmi > 0.20:
                      status = "DECELERATING_LABOR_MOMENTUM" if lmmi < p_lmmi else "STRONG_LABOR_EXPANSION"
                  elif lmmi < -0.20:
                      status = "LABOR_MARKET_DETERIORATION_RISK"
                  else:
                      status = "BALANCED_LABOR_MARKET"
              else:
                  return None
          else:
              if lmmi > 1.0:
                  status = "STRONG_LABOR_EXPANSION"
              elif lmmi > 0.20:
                  status = "MODERATE_LABOR_EXPANSION"
              elif lmmi < -0.20:
                  status = "LABOR_MARKET_DETERIORATION_RISK"
              else:
                  status = "BALANCED_LABOR_MARKET"

          return {
              "lmmi_score": lmmi,
              "payems_yoy_pct": p_growth_r,
              "unrate_yoy_diff": u_diff_r,
              "employment_strength_ratio": strength_ratio,
              "status": status
          }
      except (TypeError, ValueError):
          return None
- Interpretation:
  - LMMI > +1.00 (or rising): STRONG_LABOR_EXPANSION (Robust payroll expansion and declining/stable unemployment; accelerating labor market strength; lowers dovish Fed cut urgency)
  - +0.20 < LMMI <= +1.00 (or declining vs previous month): DECELERATING_LABOR_MOMENTUM / MODERATE_LABOR_EXPANSION (Employment expanding but losing velocity or unemployment ticking higher; late-cycle cooling)
  - -0.20 <= LMMI <= +0.20: BALANCED_LABOR_MARKET (Neutral labor signals; payroll creation roughly in line with labor force demographics)
  - LMMI < -0.20: LABOR_MARKET_DETERIORATION_RISK (Weakening payroll growth and rising unemployment; recessionary cracks widening)

### 30. OFFICIAL MACROECONOMIC RELEASE CALENDARS & COUNTDOWN ENGINE
- Purpose: Deterministically resolves scheduled release dates and computes remaining days for Tier-1 economic releases including CPI, NFP, PPI, PCE Inflation, and GDP.
- Canonical Calendar Sources:
  - BLS Schedule (CPI, NFP, PPI): https://www.bls.gov/schedule/news_release/bls.ics
  - BEA Schedule (PCE, GDP, Trade Balance): https://apps.bea.gov/API/signup/release_dates.json
- Countdown Formula:
  Days_Remaining = (Target_Date - Current_Date).days
  (Both timestamps normalized to midnight 00:00:00 UTC to prevent time-of-day distortion.)
- Status Mapping:
  - Days_Remaining == 0 : "Today"
  - Days_Remaining == 1 : "Tomorrow"
  - Days_Remaining > 1 : str(Days_Remaining) + " days remaining"
  - Days_Remaining < 0 : str(abs(Days_Remaining)) + " days ago"
- Machine-Executable Logic (Python):
  from datetime import datetime

  def macro_release_countdown(target_date_str, current_date_str):
      if not target_date_str or not current_date_str:
          return None
      try:
          t_target = datetime.strptime(str(target_date_str).strip(), '%Y-%m-%d').date()
          t_current = datetime.strptime(str(current_date_str).strip(), '%Y-%m-%d').date()
      except (ValueError, TypeError):
          return None

      delta_days = (t_target - t_current).days

      if delta_days == 0:
          status = "Today"
      elif delta_days == 1:
          status = "Tomorrow"
      elif delta_days > 1:
          status = f"{delta_days} days remaining"
      else:
          status = f"{abs(delta_days)} days ago"

      return {"days_remaining": delta_days, "status": status}
- Execution Directive for AI Agents:
  When querying scheduled release timing for forthcoming macroeconomic data:
  1. Query BLS schedule for CPI, NFP, PPI; query BEA JSON calendar for PCE, GDP.
  2. Identify nearest official scheduled release date (Target_Date).
  3. Execute macro_release_countdown logic to determine exact remaining duration with unambiguous status tags.
